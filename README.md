## 🌟 Features

- 🖥️ **Interactive Desktop Experience**: Draggable windows with macOS/Linux style window controls (close, minimize, maximize), z-index focus management, and desktop icons.
- 🚀 **Animated Boot Sequence**: Simulated BIOS boot with system checks, terminal log messages, and loading bar before revealing the desktop.
- ⌨️ **Interactive Terminal CLI**:
  - `help` — List available commands
  - `whoami` — Bio and highlights
  - `neofetch` — ASCII art & system specs
  - `ls` — List desktop files
  - `cat <file>` — Read files (`about.txt`, `contact.txt`, `skills.txt`, `projects.txt`)
  - `open <app>` — Launch any window from terminal
  - `clear`, `history`, `date`, `echo`
- 🌌 **Cosmic Canvas Particle Background**: Animated starfield particles and subtle grid overlay powered by HTML5 Canvas.
- 📂 **Dedicated Window Applications**:
  - `About.exe` — Profile, bio, and direct links
  - `Projects/` — KrishiGyan, Mockneto, VirtuGym, CivicResolver, Scalle, WeTano Engage AI, Market Trend Forecaster
  - `Experience/` — Timeline of internships (UpStride, Infosys, Webstack Academy)
  - `Skills.json` — Categorized skill badges (Languages, Frameworks, Tools, Core CS)
  - `Education.log` — Academic history (Lovely Professional University & Kendriya Vidyalaya)
  - `Awards/` — DSA achievements, Hackathon finalist, HackerRank 5-Star badges
  - `Contact.sh` — Interactive connection panel with email, LinkedIn, GitHub, phone
- 📱 **Taskbar & Context Menu**: Full bottom taskbar with app switching, real-time clock, and custom right-click context menu.

## 🚀 Running Locally

No dependencies or build steps required. Simply clone and open `index.html`:

```bash
git clone https://github.com/Prakhar1903/portfolio.git
cd portfolio
```

Run with Python HTTP server:
```bash
python3 -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
